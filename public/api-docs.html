REST API Reference

Integrate OpenRemove background removal directly into bots, services, and workflows.

GET /ping

Healthcheck endpoint to verify server status and uptime.

curl -X GET https://openremove.dgxohq.com/ping
POST /api/upload

Upload an image file (`image` form field, max 25MB). Returns a `jobId` for SSE streaming.

curl -X POST https://openremove.dgxohq.com/api/upload \
  -F "image=@photo.jpg"
GET /api/process-stream/:jobId

Server-Sent Events (SSE) stream for real-time inference progress and result URL.

curl -N https://openremove.dgxohq.com/api/process-stream/YOUR_JOB_ID
POST /inference (Local Engine Only)

Direct synchronous inference endpoint for self-hosted backend engines, returning a raw transparent PNG buffer.

curl -X POST http://localhost:5000/inference \
  -F "image=@photo.jpg" \
  --output result.png

API Limits & Data Safety

  • Max payload size: 25 MB (max 40 MP image resolution).
  • Supported MIME types: image/jpeg, image/png, image/webp, image/gif, image/bmp.
  • Zero 3rd-party cloud dependencies: images are processed directly on-premise without third-party APIs or external data sharing.
