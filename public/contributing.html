Contributing to OpenRemove

Guidelines for developers, model researchers, and contributors.

1. Fork & Development Setup

Clone the repo, install dependencies, and launch local development services: 

git clone https://github.com/DDGXO/openremove.git
cd openremove
npm install
npm start

2. Submitting Pull Requests

  • Create feature branches from main (e.g., feature/model-optimization).
  • Ensure memory safety benchmarks (<700MB peak C++ RAM) remain intact.
  • Maintain zero cloud telemetry and preserve air-gapped compatibility.

3. Reporting Issues & Model Feedback

If you discover an edge case segmentation error or edge fringing, submit an issue on GitHub with reproduction steps and sample dimensions.
